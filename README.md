## 每日速览一句话（三级优先级）

页面头部的一句话，按以下顺序取，**先到先得**：

| 优先级 | 内容 | 数据源 |
|---|---|---|
| ① | **台风预警**（有台风则整天显示 ⚠️） | 浙江水利 `typhoon.slt.zj.gov.cn` |
| ② | **IP 定位当地天气**（如「📍 广州市今日 ☀️ 晴 · 26~34℃」） | IP 定位 → open-meteo |
| ③ | **轮换库**：一言每日一句（失败回退本地 12 条池） | 一言 Hitokoto |

### IP 定位（三层保险）
1. `ipinfo.io`（https，CORS 全开）—— 主源
2. `ip-api.com`（http，中文城市名）—— 备源
3. 固定江门坐标（`22.5833,113.0833`）—— 最终兜底

### 轮换库（每日一句）
- 一言分类随机：**诗词 / 哲思 / 文学 / 影视 / 网易云**
- 当日结果存 `localStorage`，一天只换一次
- 接口失败自动回退内置 12 条静态文案
