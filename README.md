## CORS 代理（cors-proxy Worker）

`cors-proxy` Cloudflare Worker 绑定自定义域名：**`cloudflaer的workers/?url=<编码URL>`**

- 代理任意接口并附加 CORS 头（含 nmc.cn 等 HTTP-only 源）

- 全站通用：任何需要跨域的地方都可通过它访问

- 国内直连 · HTTPS · 永久方案

### 秋哥操作卡片结构（2026-08-22 起）

| 子区块 | 数据字段 | 说明 |
|---|---|---|
| 精选标的 picks | `picks_name` / `picks_detail` | 仅今日**新开仓/加仓**推荐（无则不显示） |
| **持仓管理 holdings** | `holdings` | 招行等底仓的管理动作（如"⚠️减仓警戒"）；**由推送脚本按模拟器实盘状态自动对账生成**，人工无需维护；公开页不展示具体仓位数量，仅操作比例与信号 |
| 观望 watch | `watch` | 观察池标的（带候选池状态注记如 observing-1） |

> 口径保证：qiuge_report.json 推送链路会自动读同仓 `output/simulation_state.json`（实盘模拟器账户）覆写 holdings，nav 卡片与模拟区块天然一致。

### 数据路径全景（哪些走代理 / 哪些直连）

| 区块 | 数据 | 路径 | 说明 |
|---|---|---|---|
| 风向标 | XXFI + VIX（market-live data.json） | **代理 → 直连 → jsdelivr** | proxy 无缓存保实时 |
| 风向标 | 秋哥操作（qiuge_report.json） | **代理 → 直连 → jsdelivr** | 同上 |
| 风向标 | 今日定性导语（portfolio 日报） | **代理 → 直连 → jsdelivr** | 同上 |
| 今日速览 | 60s 每日新闻（60s.viki.moe） | 国内直连（CORS 全开） | 快源 0.5s 无需代理 |

### GitHub 数据源加速（国内直连 GitHub 常超时）

风向标三个数据源均托管在 GitHub（raw），统一采用**三级切换，代理优先**：

| 优先级 | 路径 | 特点 |
|---|---|---|
| ① 代理 | CORS 代理转发（用户自建 Cloudflare Worker） | **无缓存、实时**，高频数据首选 |
| ② 直连 | raw.githubusercontent.com | 无缓存，国内可能超时 |
| ③ jsdelivr | `cdn.jsdelivr.net/gh/仓库@main/路径` | 快但有 **12h 服务端缓存**，仅最后兜底（宁旧勿无） |

> ⚠️ 经验：**jsdelivr 适合低频静态资源，不适合 30 分钟高频更新的数据**（12h 缓存会导致 XXFI/VIX/秋哥显示旧值）。高频数据必须走代理/直连。
