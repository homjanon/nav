## 每日速览（分层显示）

页面头部的速览区，**分层独立显示**：预警区（可多条）→ 天气行 → 每日一句行，各自获取，成功才显示，失败自动隐藏。

| 区块 | 内容 | 数据源 | 失败时 |

|---|---|---|---|

| ① 预警区 | **台风预警**（有台风整天显示 ⚠️ 红色） | 浙江水利 `typhoon.slt.zj.gov.cn` | 不显示 |

| ① 预警区 | **nmc 气象预警**（xx市级 / XX→市级→无则不显示，按红>橙>黄>蓝着色） | `nmc.cn` 经 cors-proxy 转发 | 不显示 |

| ② 天气 | **IP 定位当地天气**（如「📍 广州市今日 ☀️ 晴 · 26~34℃」） | IP 定位 → open-meteo（经代理加速） | 不显示 |

| ③ 每日一句 | **一言**（随机分类，当日缓存） | 一言 Hitokoto | 用本地池兜底 |

> 全部失败时显示「⏳ 每日速览暂无数据（接口暂不可用，稍后刷新）」兜底提示。

### 预警过滤规则（关注地：广东GZ + 浙江JX）

- **GZ**：广东预警中匹配「GZ市气象台」**市级**预警（排除县级），取最严重一条

- **JX**：优先「南湖」→ 无则「市气象台」市级 → 再无则**不显示**

- 等级排序：红 > 橙 > 黄 > 蓝

### IP 定位（三层保险，全失败不显示天气行）

1. `api.vore.top/api/IPdata`（**主源**，中文省/市/区三级 + 市级 adcode，CORS 全开）—— 支持区县级定位

2. `myip.ipip.net/json`（国内权威 IP 库，https + CORS 全开，精确到市）—— 备源

3. `ipinfo.io`（海外源，有经纬度，英文城市名）—— 国外 IP 时才会用到

> 三层全部失败时天气行**直接不显示**（与台风/预警失败行为一致，无固定兜底坐标）。

> ⚠️ **ipip.net 只返回城市名不返回经纬度** → 内置 60+ 常用城市坐标表（全国省会 +地级市 + 港澳台）按城市名匹配坐标，再喂给 Open-Meteo 取天气。

### 区县级天气（2026-08-30 起）

- vore 主源返回区县名（如「越秀区」）时，拉取**阿里 DataV GeoAtlas** 公开数据 `geo.datav.aliyun.com/areas_v3/bound/{市级adcode}_full.json`（免 key，CORS 全开）→ 前缀匹配区县中文名（vore「龙岗」↔ DataV「龙岗区」）→ 取区县中心坐标喂 Open-Meteo
- DataV 结果按 `sessionStorage` **当日缓存**（同一城市一天只拉一次，69~162KB）
- 显示格式：有区县 → `📍 广州·越秀 今日 …`（自动去尾部「区/县/旗」字）；匹配失败/无区名 → 回落市级 `📍 深圳 今日 …`（宁缺毋错）
- 国内城市恒中文（vore/ipip 均中文源）；ipinfo 仅国外 IP 触发

> 曾用 `ip-api.com` 作备源，但免费版仅支持 http（https 返回 403），https 页面会被浏览器拦混合内容，故弃用。百度千帆 `qifu-api.baidubce.com` district 接口已下线（ResourceNotFound），不可用。

## CORS 代理（cors-proxy Worker）

`cors-proxy` Cloudflare Worker 绑定自定义域名：**`cloudflaer的workers/?url=<编码URL>`**

- 代理任意接口并附加 CORS 头（含 nmc.cn 等 HTTP-only 源）

- 全站通用：任何需要跨域的地方都可通过它访问

- 国内直连 · HTTPS · 永久方案

### GitHub 数据源加速（国内直连 GitHub 常超时）

今日要点三个数据源均托管在 GitHub（raw），统一采用**三级切换，代理优先**：

| 优先级 | 路径 | 特点 |
|---|---|---|
| ① 代理 | CORS 代理转发（用户自建 Cloudflare Worker） | **无缓存、实时**，高频数据首选 |
| ② 直连 | raw.githubusercontent.com | 无缓存，国内可能超时 |
| ③ jsdelivr | `cdn.jsdelivr.net/gh/仓库@main/路径` | 快但有 **12h 服务端缓存**，仅最后兜底（宁旧勿无） |

> ⚠️ 经验：**jsdelivr 适合低频静态资源，不适合 30 分钟高频更新的数据**（12h 缓存会导致 XXFI/VIX/秋哥显示旧值）。高频数据必须走代理/直连。
