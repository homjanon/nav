## 每日速览（三级独立显示）

页面头部的一句话，**三级并行独立**：各自获取，成功才显示，失败自动隐藏，项间用 `·` 分隔。

| 级 | 内容 | 数据源 | 失败时 |
|---|---|---|---|
| ① | **台风预警**（有台风则整天显示 ⚠️，红色标注） | 浙江水利 `typhoon.slt.zj.gov.cn` | 不显示 |
| ② | **IP 定位当地天气**（如「📍 广州市今日 ☀️ 晴 · 26~34℃」） | IP 定位 → open-meteo | 不显示 |
| ③ | **每日一句**（一言，随机分类，当日缓存） | 一言 Hitokoto | 不显示 |

> 全部失败时显示「⏳ 每日速览暂无数据（接口暂不可用，稍后刷新）」兜底提示。

### IP 定位（三层保险）
1. `ipinfo.io`（https，CORS 全开）—— 主源
2. `ip-api.com`（http，中文城市名）—— 备源
3. 固定江门坐标（`22.5833,113.0833`）—— 最终兜底

### 每日一句（原轮换库）
- 一言分类随机：**诗词 / 哲思 / 文学 / 影视 / 网易云**
- 当日结果存 `localStorage`，一天只换一次
- **获取失败则该级不显示**（符合"获取不到则不显示"规则）

## 部署

- 纯静态单页（`index.html`），无构建，无依赖
- GitHub Pages：`Settings → Pages → Deploy from branch → main → / (root)`
- 自定义域名：`CNAME` 文件指向 `hellohopo.dpdns.org`，DNS 由 Cloudflare 托管
