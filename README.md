## 每日速览（分层显示）

页面头部的速览区，**分层独立显示**：预警区（可多条）→ 天气行 → 每日一句行，各自获取，成功才显示，失败自动隐藏。

| 区块 | 内容 | 数据源 | 失败时 |
|---|---|---|---|
| ① 预警区 | **台风预警**（有台风整天显示 ⚠️ 红色） | 浙江水利 `typhoon.slt.zj.gov.cn` | 不显示 |
| ① 预警区 | **nmc 气象预警**（江门市级 / 重庆万州→市级→无则不显示，按红>橙>黄>蓝着色） | `nmc.cn` 经 cors-proxy 转发 | 不显示 |
| ② 天气 | **IP 定位当地天气**（如「📍 广州市今日 ☀️ 晴 · 26~34℃」） | IP 定位 → open-meteo | 不显示 |
| ③ 每日一句 | **一言**（随机分类，当日缓存） | 一言 Hitokoto | 用本地池兜底 |

> 全部失败时显示「⏳ 每日速览暂无数据（接口暂不可用，稍后刷新）」兜底提示。

### 预警过滤规则（关注地：广东江门 + 重庆万州）
- **江门**：广东预警中匹配「江门市气象台」**市级**预警（排除恩平/台山等县级），取最严重一条
- **重庆万州**：优先「万州」→ 无则「重庆市气象台」市级 → 再无则**不显示**
- 等级排序：红 > 橙 > 黄 > 蓝

### IP 定位（三层保险）
1. `ipinfo.io`（https，CORS 全开）—— 主源
2. `ip-api.com`（http，中文城市名）—— 备源
3. 固定江门坐标（`22.5833,113.0833`）—— 最终兜底

### 每日一句
- 一言分类随机：**诗词 / 哲思 / 文学 / 影视 / 网易云**
- 当日结果存 `localStorage`，一天只换一次
- 一言获取失败用本地兜底池（12 条名言/生活提示）

## CORS 代理（cors-proxy Worker）

`cors-proxy` Cloudflare Worker 绑定自定义域名：**`https://proxy.hellohopo.dpdns.org/?url=<编码URL>`**

- 代理任意接口并附加 CORS 头（含 nmc.cn 等 HTTP-only 源）
- 全站通用：任何需要跨域的地方都可通过它访问
- 国内直连 · HTTPS · 永久方案
